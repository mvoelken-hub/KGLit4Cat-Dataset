# Repo4Cat

**Authors:** Volodymyr Kushnarenko, Michael Liebau, David Linke, et al. (HLRS Stuttgart)
**Year:** 2025
**Venue:** IEEE IDAACS 2025
**File:** `docs/literature/Repo4Cat_How_to_Setup_Configure_and_Operate_a_Data_Repository_for_Catalysis-Related_Sciences.pdf`

## Abstract
Describes creation of Repo4Cat, NFDI4Cat's central data repository. Covers software selection, setup, configuration, functionality extension, adaptation to catalysis-specific requirements, and maintenance. Focus on know-how collected during the process.

## Key Findings
- Built on existing repository software (not from scratch) — pragmatic approach
- Key requirements: FAIR storage, multipurpose storage/processing, various formats, versioning, GUI, API, working spaces, data publication
- Working spaces for private/industry collaboration with IP protection
- Support, training, and user community building are critical

## Relevance
Practical infrastructure implementation. Relevant to [[catalysis-data-infrastructure]] and [[nfdi4cat]]. https://repository.nfdi4cat.org/
