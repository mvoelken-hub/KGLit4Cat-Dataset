# Data as a Key Resource in Catalysis

**Authors:** Pedro S. F. Mendes, Núria López, Sandip De, Rebecca Fushimi, Ramazan Yildirim, Annette Trunschke
**Year:** 2025
**Venue:** ChemCatChem
**File:** `docs/literature/ChemCatChem - 2025 - Mendes - Data as a Key Resource in Catalysis  A Community Account.pdf`

## Abstract
Community perspective analyzing challenges and solutions for FAIR data management in catalysis. Based on insights from ICC 2024, NAM29 2025, EuropaCat 2025. Proposes mandatory FAIR data depositing before publication and consensualized top-down guidelines.

## Key Findings
- Catalysis has dataset-to-article ratio ~1/100 — data typically not shared
- Even available data hindered by standardization and metadata deficiencies
- Most data not machine-readable, unsuitable for data science
- Short-term: mandatory FAIR data depositing prior to publication + top-down guidelines + easy-to-use tools
- Community debates: legal, infrastructural, and human factors in AI-assisted knowledge acquisition

## Relevance
Community consensus on data challenges. Relevant to [[catalysis-data-infrastructure]] and [[fair-data-for-catalysis]].
