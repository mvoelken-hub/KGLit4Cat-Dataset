# KG-Hub

**Authors:** J. Harry Caufield, Tim Putman, Kevin Schaper, et al. (Lawrence Berkeley National Laboratory)
**Year:** 2023
**Venue:** Bioinformatics 39(7): btad418
**File:** `docs/literature/btad418.pdf`

## Abstract
Platform enabling standardized construction, exchange, and reuse of knowledge graphs. Features modular extract-transform-load pattern, Biolink Model compliance, OBO ontology integration, versioned builds, cloud infrastructure, and graph ML tools.

## Key Findings
- Modular ETL pattern for KG construction compliant with Biolink Model
- Easy integration of OBO ontologies
- Cached downloads, versioned/automatically updated builds with stable URLs
- Current projects: COVID-19, drug repurposing, microbial-environmental interactions, rare disease
- Integrated with graph ML tools: node embeddings, link prediction, node classification

Infrastructure for KG construction. Relevant to [[knowledge-graph-infrastructure]] and [[ontology-resources]]. https://kghub.org
