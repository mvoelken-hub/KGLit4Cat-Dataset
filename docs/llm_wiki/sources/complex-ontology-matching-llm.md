# Complex Ontology Matching with LLM Embeddings

**Authors:** Guilherme Santos Sousa, Rinaldo Lima, Cassia Trojahn
**Year:** 2025
**Venue:** arXiv (IRIT / Université de Toulouse)
**File:** `docs/literature/2502.13619v1.pdf`

## Abstract
Integrates LLMs into an approach for generating expressive (complex) correspondences based on alignment need and ABox-based relation discovery. Four architectural modifications: label embedding similarity, embeddings of SPARQL results, subgraph embeddings, instance embeddings.

## Key Findings
- LLM integration surpasses all other models (word embeddings, sentence embeddings)
- 45% increase in F-measure over baseline CANARD approach
- Addresses complex correspondences (logical constructors, transformation functions)
- Pre-trained models circumvent need for reference alignments
