# Catalyst Informatics

**Authors:** Keisuke Takahashi, Junya Ohyama, Shun Nishimura, Jun Fujima, Lauren Takahashi, Takeaki Uno, Toshiaki Taniike
**Year:** 2023
**Venue:** Chem. Commun. (Feature Article)
**File:** `docs/literature/6fa62d1bb122101ff53ae3bbacae2f1ff85a6ab133bcb3dd7c497091916e3870.pdf`

## Abstract
Proposes catalyst informatics as an alternative to trial-and-error catalyst design. Three key concepts: experimental catalysts database, knowledge extraction via data science, catalysts informatics platform. Methane oxidation as prototype reaction.

## Key Findings
- Catalyst design is a multi-dimensional problem (composition, structure, oxidation state, experimental conditions)
- Three pillars: experimental database, knowledge extraction, informatics platform
- Big data generation via high-throughput experiments
- Machine learning and catalyst network methods
- Catalyst design from small data
- Future: ontology for catalyst informatics
