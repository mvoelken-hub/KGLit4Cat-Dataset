# FAIR Data in Local Catalysis Infrastructure

**Authors:** Abdulrhman Moshantaf, Michael Wesemann, Simeon Beinlich, et al. (Fritz Haber Institute)
**Year:** 2024
**Venue:** Catal. Sci. Technol. 14(21): 6186–6197
**File:** `docs/literature/d4cy00693c.pdf`

## Abstract
Presents methods for digital and automatic data acquisition and storage in catalysis experiments using open-source software. Implements digitalization concept with machine-readable SOPs using EPICS (Experimental Physics and Industrial Control System). Fully automated pipeline: data acquisition → standardized analysis → database upload → relationship generation. APIs enable local and repository-level data exchange.

## Key Findings
- Automated reactor for catalytic tests using EPICS open-source software
- Machine-readable standard operating procedures (SOPs)
- Fully automated: acquisition → analysis → database upload → relationship generation
- APIs for local infrastructure and overarching repository data exchange
- Paves way for autonomous catalyst discovery and ML applications
