# NOMAD Catalysis Plugin

**Authors:** Julia Schumann, Hampus Näström, Michael Götze, et al. (Fritz Haber Institute / Humboldt-Universität)
**Year:** 2025
**Venue:** chemrxiv preprint
**File:** `docs/literature/chemrxiv-2025-kx99k.pdf`

## Abstract
New plugin within the NOMAD platform for managing and publishing heterogeneous catalysis data. Enables structured experimental data/metadata upload with built-in visualization and alignment to Voc4Cat vocabulary. Offers intuitive search for catalytic reactions, catalyst materials, conditions, and kinetic properties.

## Key Findings
- Structured repository for experimental catalysis data (previously lacking)
- Built-in alignment to Voc4Cat community vocabulary
- Search functionality: reactions, catalyst materials, conditions, kinetic properties
- Foundation for advanced data analytics and ML applications
- Supports FAIR data principles

## Relevance
Infrastructure for FAIR catalysis data. Relevant to [[catalysis-data-infrastructure]], [[nfdi4cat]], and [[voc4cat]].
