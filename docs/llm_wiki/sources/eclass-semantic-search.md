# ECLASS-Augmented Semantic Product Search

**Authors:** Nico Baumgart, Markus Lange-Hegermann, Jan Henze (OWL University / Phoenix Contact)
**Year:** 2026
**Venue:** arXiv (cs.IR)
**File:** `docs/literature/eclass-augmented-semantic-product-search-for-electronic-components-2604.19664v1.pdf`

## Abstract
Evaluation of LLM-assisted dense retrieval for semantic product search on industrial electronic components. Integrates hierarchical semantics from ECLASS standard into embedding-based retrieval. Hit Rate@5 of 94.3% vs 31.4% for BM25.

## Key Findings
- Dense retrieval + re-ranking substantially outperforms BM25 on expert queries
- ECLASS hierarchical metadata provides semantic bridge between user intent and product descriptions
- Foundation model baselines exceeded in both effectiveness and efficiency
- Relevant for factory automation and LLM-based agent workflows

## Relevance
Industrial ontology application (ECLASS). Relevant to [[ontology-development]] and [[ontology-resources]].
