# Knowledge Extraction from Scientific Literature in Catalysis

**Authors:** Yue Zhang, Cong Wang, Mya Soukaseum, Dionisios G. Vlachos, Hui Fang
**Year:** 2022
**Venue:** J. Chem. Inf. Model.
**File:** `docs/literature/unleashing-the-power-of-knowledge-extraction-from-scientific-literature-in-catalysis.pdf`

## Abstract
Constructs the first information extraction benchmark dataset for catalysis and develops a general extraction framework that accurately extracts catalysis-related entities from scientific literature with 90% accuracy. Demonstrates entity-aware search engine and correlation analysis.

## Key Findings
- First benchmark dataset for catalysis-related information extraction from full-text journal articles
- Six entity types: catalyst, reaction, reactant, product, characterization, treatment
- 90% extraction accuracy
- Article selection module (binary classifier) identifies catalysis-relevant articles
- Entity-aware search engine and correlation analysis system built on extracted knowledge

## Methodology
- NLP-based information extraction pipeline
- Binary classifier for article selection
- Named entity recognition for six catalysis entity types
- Focused on catalytic plastic conversion as application domain
