# NFDI4Cat: Unified Research Data Infrastructure for Catalysis

**Authors:** Christoph Wulf, Matthias Beller, et al. (Leibniz-Institute for Catalysis)
**Year:** 2021
**Venue:** ChemCatChem
**File:** `docs/literature/ChemCatChem - 2021 - Wulf - A Unified Research Data Infrastructure for Catalysis Research   Challenges and Concepts.pdf`

## Abstract
Perspective on implementing FAIR data principles in catalysis. Presents NFDI4Cat concept serving all aspects of catalysis research. Vision for integrating research data along the catalysis value chain (molecule to chemical process). Discusses ontologies, metadata, infrastructure, IP, and community embedding.

## Key Findings
- Catalysis is highly interdisciplinary (heterogeneous, homogeneous, bio-, electro-, photo-catalysis)
- NFDI4Cat proposes integrating all research data along catalysis value chain
- Core development topics: ontologies, metadata, infrastructure, IP, community embedding
- FAIR data (Findable, Accessible, Interoperable, Reusable) as guiding principle
