# FAIR for Digital Twins

**Authors:** Diana Peters, Sirko Schindler  
**Year:** 2023  
**Venue:** CEAS Space Journal 16:367-374  
**File:** `docs/literature/s12567-023-00506-y.pdf`

## Abstract
Argues that FAIR principles from scientific data management can help address data-exchange problems in industrial digital twins, especially in aerospace manufacturing. The paper emphasizes heterogeneous data sources, institutional boundaries, machine-actionable descriptions, controlled vocabularies, Semantic Web technologies, authentication, authorization, and provenance.

## Key Findings
- Digital twins aggregate data from many heterogeneous sources across micro and macro levels of a product or process.
- FAIR does not imply open data; restricted access can still be FAIR if restrictions are machine-actionable and protocols support authentication and authorization.
- Semantic Web technologies, URLs, HTTP, RDF, SPARQL, controlled vocabularies, and linked data are presented as core implementation tools.
- Interoperability requires both technical format compatibility and semantic comparability, including units and property definitions.
- Reusability depends on provenance, long lifecycle documentation, licensing/usage conditions, and the ability to migrate or reinterpret models over time.

## Relevance
Useful for thesis arguments that FAIR requirements overlap and extend beyond open access. It is an adjacent industrial analogue for SIMONE's concern with heterogeneous packages, machine-actionable metadata, semantic grounding, explicit access conditions, units, and provenance.
