# NFDI4Chem

**Authors:** Christoph Steinbeck, Oliver Koepler, Sonja Herres-Pawlis, et al.
**Year:** 2023
**Venue:** Chemistry International
**File:** `docs/literature/10.1515_ci-2023-0103.pdf`

## Abstract
Overview of NFDI4Chem, the chemistry consortium within Germany's NFDI. Describes Smart Lab concept (ELN + instrument integration), repository federation, and infrastructure for FAIR chemistry research data.

## Key Findings
- Smart Lab: ELN (Chemotion) + measurement data integration + data processing tools + repository transfer
- Chemotion ELN as reference implementation — supports SMILES, InChI, jcamp.dx
- Federated repository infrastructure for molecule/reaction/characterization data
- Teaching and training for cultural change in chemistry
- Open-source approach for international collaboration

Sister consortium to [[nfdi4cat]]. Relevant to [[catalysis-data-infrastructure]] and [[fair-data-for-catalysis]].
