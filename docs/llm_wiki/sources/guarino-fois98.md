# Formal Ontology and Information Systems (Guarino 1998)

**Authors:** Nicola Guarino
**Year:** 1998
**Venue:** FOIS'98 Proceedings (IOS Press)
**File:** `docs/literature/Formal_Ontology_and_Information_Systems-FOIS98.pdf`

## Abstract
Seminal paper clarifying the term "ontology" in computer science. Distinguishes philosophical Ontology (conceptualization) from AI ontology (engineering artifact = vocabulary + explicit assumptions). Introduces ontology-driven information systems.

## Key Concepts
- Ontology (AI sense) = specific vocabulary + set of explicit assumptions about intended meaning (typically first-order logical theory)
- Conceptualization = philosophical reading of ontology (vision of the world, language-independent)
- Two ontologies can share same conceptualization but differ in vocabulary
- Ontology plays central role in information systems: information resources, user interfaces, application programs
- Ontological commitment = adopting a particular conceptualization
