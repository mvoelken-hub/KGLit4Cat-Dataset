# FAIR Data Principles in Biopharmaceutical R&D

**Authors:** John Wise, Alexandra Grebe de Barron, Andrea Splendiani, Beeta Balali-Mood, Drashtti Vasant, Eric Little, Gaspare Mellino, Ian Harrow, Ian Smith, Jan Taubert, Kees van Bochove, Martin Romacker, Peter Walgemoed, Rafael C. Jimenez, Rainer Winnenburg, Tom Plasterer, Vibhor Gupta, Victoria Hedley  
**Year:** 2019  
**Venue:** Drug Discovery Today 24(4):933-938  
**File:** `docs/literature/1-s2.0-S1359644618303039-main.pdf`

## Abstract
Perspective article from the Pistoia Alliance on FAIR implementation in biopharmaceutical R&D. It argues that FAIR data is a foundation for digital transformation, AI, machine learning, automation, and cross-institution collaboration, but requires investment across people, process, technology, governance, data stewardship, and knowledge representation.

## Key Findings
- FAIR is framed as an enterprise data-management strategy that enables machine readability, reuse, scalability, analytics, and automation.
- Implementation barriers include cost, culture, training, governance, technology gaps, standards selection, and executive buy-in.
- Data stewardship is needed at the point of data collection because quality and integration problems often appear only later during analysis and reuse.
- Knowledge representation requires consensus on ontologies and suitable languages such as RDF and OWL.
- The proposed path starts with a FAIR-compliant data catalogue, then federated/virtual access infrastructure, then interoperability at metadata and individual data-point levels.

## Relevance
Useful as an adjacent industry source for FAIR implementation and for the claim that FAIR is not just a repository problem. It supports thesis language about data stewardship, cultural change, governance, ontology consensus, and the importance of making data machine-readable for AI workflows. It is not catalysis-specific.
