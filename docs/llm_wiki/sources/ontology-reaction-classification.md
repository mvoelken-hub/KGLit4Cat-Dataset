# Ontology-Based Data Pipeline for Reaction Classification

**Authors:** Hendrik Borgelt, Frederick Gabriel Kitel, Norbert Kockmann (TU Dortmund)
**Year:** 2025
**Venue:** Computers 14(8): 311 (MDPI)
**File:** `docs/literature/computers-14-00311.pdf`

## Abstract
Extends established ontologies by refining logical relations and integrating semantic tools (OWL, SHACL). Incorporates APIs from chemical databases (KEGG, PubChem). Key innovation: automatic decomposition of chemical substances to identify functional groups for generalized reaction classification.

## Key Findings
- Extends Reac4Cat ontology with semantic reaction classification
- Automatic functional group identification via database entries and chemical identifiers
- OWL + SHACL for reasoning and constraints
- GUI for knowledge graph interaction, ontological reasoning, querying
- Improved specificity over predecessors
- Pipeline for knowledge insertion and enrichment

## Relevance
Ontology application for catalysis reaction data. Relevant to [[catalysis-ontologies]], [[voc4cat]], and [[nfdi4cat]].
