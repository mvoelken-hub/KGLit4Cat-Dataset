# Fine-Tuning LLMs for Chemical Text Mining

**Authors:** Wei Zhang, Qinggong Wang, Xiangtai Kong, et al. (Shanghai Institute of Materia Medica)
**Year:** 2024
**Venue:** Chem. Sci. 15(27): 10600–10611
**File:** `docs/literature/d4sc00924j.pdf`

## Abstract
Explores fine-tuned LLMs on five chemical text mining tasks: compound entity recognition, reaction role labelling, MOF synthesis extraction, NMR data extraction, and reaction paragraph-to-action-sequence conversion. Fine-tuned ChatGPT models achieve 69–95% accuracy with minimal annotated data, outperforming task-adaptive pre-training models. Open-source Mistral and Llama3 show competitive abilities.

## Key Findings
- Five chemical text mining tasks benchmarked
- Fine-tuned GPT-3.5-turbo excels in all tasks with minimal annotated data
- Outperforms task-adaptive pre-training models using larger in-domain data
- Open-source Mistral and Llama3 show competitive performance
- Low-code capability: fine-tuned LLMs as flexible toolkits for chemical data acquisition
