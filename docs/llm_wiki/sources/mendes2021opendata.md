# Open Data in Catalysis: Big Picture to Small Data

**Authors:** Pedro S. F. Mendes, Sébastien Siradze, Laura Pirro, Joris W. Thybaut
**Year:** 2021
**Venue:** ChemCatChem 13(3): 836–850
**File:** `docs/literature/ChemCatChem - 2020 - Mendes - Open Data in Catalysis  From Today s Big Picture to the Future of Small Data.pdf`

## Abstract
Mini-review examining the landscape of open data in catalysis. Contrasts "big data" approaches (high-throughput experimentation, ML) with "small data" approaches (few examples, transfer learning). Argues for open data as the foundation for both paradigms.

## Key Findings
- Big picture: high-throughput experimentation generates large datasets
- Small data: realistic scenario in catalysis — few examples per system
- Open data essential for both paradigms
- Transfer learning and active learning as bridges between big and small data
