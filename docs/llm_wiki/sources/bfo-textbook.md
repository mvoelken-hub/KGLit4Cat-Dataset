## Abstract
Textbook on ontology design using Basic Formal Ontology (BFO) as upper-level ontology. Covers what an ontology is, taxonomy design, universals/classes/relations, and the process of building domain ontologies grounded in BFO.

## Key Concepts
- Ontology = representational artifact comprising a taxonomy as proper part, representing universals, defined classes, and relations
- Taxonomy = hierarchy of terms denoting types linked by subtype relations
- Entity = anything that exists (objects, processes, qualities)
- Ontologies as representational artifacts supporting scientific theory development

## Relevance
Foundational reference for [[formal-ontology]] and [[ontology-development]]. BFO is a widely used upper-level ontology.
