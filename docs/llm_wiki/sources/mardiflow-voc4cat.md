# MaRDIFlow + Voc4Cat Integration

**Authors:** Pavan L. Veluvali, Jan Heiland, Peter Benner (Max Planck Institute, Magdeburg)
**Year:** 2025
**Venue:** CoRDI 2025
**File:** `docs/literature/veluvali_3652467.pdf`

## Abstract
Integrates Voc4Cat ontology into MaRDIFlow computational workflow framework. Voc4Cat serves as backbone for annotating metadata dependencies and supporting workflow descriptions. RESTful APIs enable real-time vocabulary querying and metadata validation. Working example: methanization reactor model.

## Key Findings
- MaRDIFlow: computational workflow framework with metadata-driven descriptions
- Voc4Cat integration via RESTful APIs for real-time vocabulary querying
- Components defined by input-output relations; metadata used interchangeably and redundantly
- Redundancy as strength: ensures compatibility during execution, supports reproducibility
- Working example: catalysis-based methanization reactor model

## Relevance
Practical ontology integration in computational workflows. Relevant to [[voc4cat]], [[catalysis-data-infrastructure]], and [[nfdi4cat]].
