# Improvement of Data and Metadata Quality in Catalysis

**Authors:** Nadiia Huskova, Yuliia Dikova, Taras Petrenko, Thomas Bönisch (HLRS Stuttgart)
**Year:** 2025
**Venue:** Catal. Today 446: 115111
**File:** `docs/literature/1-s2.0-S0920586124006059-main.pdf`

## Abstract
Comprehensive use case (UC) collection methodology for improving data and metadata quality in catalysis research within NFDI4Cat. Includes detailed guidelines for information collection, evaluation against quality criteria, standardization via ontology mapping, and semantic representation in RDF.

## Key Findings
- Use case-driven methodology for research workflow and data analysis
- Standardization: mapping data/metadata to ontologies and vocabularies (RDF)
- Covers biocatalysis, homogeneous catalysis, and heterogeneous catalysis
- Semantic framework enables machine-readable, linked, cross-referenced data

## Relevance
Practical methodology for data quality in NFDI4Cat. Relevant to [[catalysis-data-infrastructure]], [[nfdi4cat]], and [[fair-data-for-catalysis]].
