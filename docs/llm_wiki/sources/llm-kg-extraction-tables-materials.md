# LLM KG Extraction from Materials Tables

**Authors:** Max Dreger, Kourosh Malek, Michael Eikerling
**Year:** 2025
**Venue:** Digital Discovery 4
**File:** `docs/literature/d4dd00362d.pdf`

## Abstract
Presents a semi-automated data ingestion pipeline that transforms non-standardized R&D tables in materials science into knowledge graphs. The pipeline combines LLM-based entity recognition and relationship extraction with rule-based feedback loops and integrates the result into a graph database with semantic search.

## Key Findings
- Targets tabular data rather than prose-only literature.
- Uses LLMs plus rule-based feedback for entity and relation extraction.
- Produces graph structures to improve data interoperability and accessibility.
- Connects extraction directly to graph database and semantic search infrastructure.
