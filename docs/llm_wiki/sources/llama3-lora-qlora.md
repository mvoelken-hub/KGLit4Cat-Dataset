# LLaMA3 LoRA/QLoRA Fine-tuning

**Authors:** Rajvardhan Patil, Priyanka Khot, Venkat Gudivada
**Year:** 2025
**Venue:** Applied Sciences 15: 3087
**File:** `docs/literature/applsci-15-03087-v2.pdf`

## Abstract
Demonstrates improvement over base LLaMA3-8B using LoRA and QLoRA for sentiment analysis (sequence classification). Analyzes effects of hyperparameter adjustments (r and α) and tradeoffs between efficiency and memory savings.

## Relevance
Technical reference for LLM fine-tuning methods. Relevant to [[chemical-llms]] (fine-tuning methodology applicable to domain-specific models).
