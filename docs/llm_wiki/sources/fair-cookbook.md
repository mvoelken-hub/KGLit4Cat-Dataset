# FAIR Cookbook

**Authors:** Philippe Rocca-Serra, Wei Gu, Vassilios Ioannidis, Tooba Abbassi-Daloii, Salvador Capella-Gutierrez, Ishwar Chandramouliswaran, Andrea Splendiani, Tony Burdett, Robert T. Giessmann, David Henderson, et al.; the FAIR Cookbook Contributors; Susanna-Assunta Sansone  
**Year:** 2023  
**Venue:** Scientific Data 10:292  
**File:** `docs/literature/s41597-023-02166-3.pdf`

## Abstract
Presents the FAIR Cookbook as an open, online collection of practical recipes for implementing FAIR data practices, mainly in the life sciences. The paper frames FAIR principles as widely endorsed but often too aspirational for direct implementation, and positions the Cookbook as a bridge from high-level principles to operational steps, tooling, standards, maturity indicators, and training material.

## Key Findings
- FAIR implementation needs practical recipes, not only principle-level statements.
- The Cookbook organizes guidance around FAIR components, infrastructure, FAIRness assessment, and example FAIRified datasets.
- Recipes cover identifiers, chemical structures, search engine optimization, secure transfer, licensing, selecting terminologies and ontologies, ontology services, provenance, and metadata types.
- The Cookbook itself is implemented as a FAIR resource using persistent recipe identifiers, machine-readable metadata, JSON-LD, ORCID, CreDiT roles, open licensing, and search infrastructure.
- Industrial and pharmaceutical use cases suggest that FAIR guidance is useful for evaluating file-based states, designing data lakes, identifying missing metadata, and justifying infrastructure investment.

## Relevance
Useful as a generic FAIR implementation source for thesis sections that distinguish FAIR principles from operational FAIRification. It supports claims that FAIR work requires practical recipes, metadata/provenance/licensing guidance, maturity indicators, and community-maintained tooling, but it is not catalysis-specific.
