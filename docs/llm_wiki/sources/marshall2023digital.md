# Achieving Digital Catalysis

**Authors:** Clara Patricia Marshall, Julia Schumann, Annette Trunschke (Fritz Haber Institute)
**Year:** 2023
**Venue:** Angew. Chem. Int. Ed. 62(30): e202302971
**File:** `docs/literature/Angew Chem Int Ed - 2023 - Marshall - Achieving Digital Catalysis  Strategies for Data Acquisition  Storage and Use.pdf`

## Abstract
Viewpoint article analyzing the current state of data infrastructure in heterogeneous catalysis and proposing solutions. Discusses FAIR data principles, types of (meta-)data from catalyst synthesis to functional analysis, and a working concept for local data acquisition and storage.

## Key Findings
- Catalyst data complexity: multiple length/time scales, coupled processes, chemical feedback
- FAIR data principles as guiding framework for digital catalysis
- Implemented working concept for local data acquisition and storage
- Integration of experiment and theory requires high data quality and metadata
- Close interdisciplinary collaboration essential
