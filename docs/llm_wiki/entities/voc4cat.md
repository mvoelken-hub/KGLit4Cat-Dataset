# Voc4Cat

**Type:** SKOS vocabulary
**Developer:** NFDI4Cat consortium
**Format:** SKOS (Simple Knowledge Organization System)

## Description
Domain-specific, open, community-driven vocabulary for catalysis-related sciences. Promotes standardization and consistent usage of vocabulary, concepts, and definitions. Used as backbone for annotating metadata in catalysis workflows.

## Applications
- **MaRDIFlow integration** ([[mardiflow-voc4cat]]): RESTful APIs for real-time vocabulary querying and metadata validation during workflow construction/execution
- **NOMAD catalysis plugin** ([[nomad-catalysis-plugin]]): Built-in alignment to Voc4Cat for long-term interpretability
- **NFDI4Cat White Paper** ([[nfdi4cat-whitepaper]]): Part of semantic framework for catalysis RDM
