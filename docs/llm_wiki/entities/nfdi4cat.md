# NFDI4Cat

**Full name:** National Research Data Infrastructure for Catalysis-Related Sciences
**Country:** Germany
**Funding:** DFG Project 441926934
**Website:** https://nfdi4cat.org

## Description
NFDI4Cat is the German national consortium for research data infrastructure in catalysis. Part of the broader NFDI (Nationale Forschungsdateninfrastruktur) initiative. Aims to create a unique research data infrastructure covering all aspects of catalysis research.

## Key Components
- **Repo4Cat** ([[repo4cat]]): Central data repository — https://repository.nfdi4cat.org/
- **Voc4Cat**: Domain-specific SKOS vocabulary for catalysis
- **ChemDCAT-AP** ([[chemdcat-ap]]): Shared metadata profile with NFDI4Chem
- **Ontologies4Cat** ([[ontologies4cat]]): Ontology landscape survey
- **NOMAD catalysis plugin** ([[nomad-catalysis-plugin]]): Data management plugin
- **Reac4Cat**: Reaction classification ontology
- **White Paper** ([[nfdi4cat-whitepaper]]): Ontology-based data management guidance

## Sister Consortium
[[nfdi4chem]] — NFDI4Chem covers broader chemistry. Both share ChemDCAT-AP as metadata foundation.
